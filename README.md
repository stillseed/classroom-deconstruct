# Classroom Deconstruct

> **Unlearn. Unmask. Transform.**

A disruption in the traditional learning landscape. Neither a training, a leadership course, nor a wellness retreat — a unique space for those ready to peel back the layers, question their beliefs, and discover who they are underneath everything they've been taught to be.

## The Five Pillars

| Pillar | Elements | Essence |
|--------|----------|---------|
| **LEAD** | Listen · Engage · Awaken · Discern | The journey inward, before leading others |
| **STAY** | Settle · Track · Allow · Yield | The art of presence under pressure |
| **RISE** | Root · Inspire · Serve · Embody | Reclaiming authenticity, vision & purpose |
| **BURN** | Break · Unmask · Reveal · Nourish | Dismantling what no longer serves |
| **HOLD** | Hear · Offer · Lean · Deepen | Becoming safe space for others to heal |

## 10-Week Facilitator Training

**Phase 1: Foundation (Weeks 1–2)**
- Orientation & Philosophy
- Holding Space Foundations

**Phase 2: Pillar Embodiment (Weeks 3–7)**
- LEAD, STAY, RISE, BURN, HOLD — each with experiential immersion, peer practice, and somatic awareness

**Phase 3: Mastery (Weeks 8–10)**
- Facilitation Skills Masterclass
- Final Practicum (60-90 min observed session)
- Integration, Closing & Certification

## Deploy to GitHub Pages

### Option 1: Drag & Drop (Easiest)
1. Download the repository as a ZIP
2. Go to [github.com/new](https://github.com/new)
3. Name it `classroom-deconstruct`, make it **Public**
4. Click **"Add file" → "Upload files"**
5. Drag all files (keep `assets/` folder structure)
6. Go to **Settings → Pages**
7. Source: **main** branch, **/ (root)** folder
8. Your site is live at `https://[username].github.io/classroom-deconstruct/`

### Option 2: Git Command Line
```bash
git clone https://github.com/YOUR_USERNAME/classroom-deconstruct.git
cd classroom-deconstruct
# copy files here
git add .
git commit -m "Initial website deploy"
git push origin main
```

### Custom Domain (Optional)
1. Edit the `CNAME` file with your domain
2. Add the GitHub Pages IP addresses to your DNS A records:
